## 1. Šta je projekat

Redizajn sajta njemačke firme **terraFIBER** (FTTH / izgradnja optičkih mreža, Neuenkirchen).
Statički HTML/CSS/JS, bez build koraka. Kasnije se predaje developeru.

| | |
|---|---|
| GitHub | `emiretfde/terrafiber` (grana `main`) |
| Live (Cloudflare Pages, auto-deploy iz `main`, ~1–2 min) | https://terrafiber.pages.dev/ |
| Rezervna stabilna verzija — **NE DIRATI** | grana `stable-v9-de-nl-en` |
| Referenca za Konzept C | `emiretfde/geoexpert` → https://geoexpert-aes.pages.dev/ |

Sajt je sakriven od Google-a (`noindex` u meta tagu i u `_headers`) — **ostaviti tako** dok klijent ne odobri.

## 2. Tri koncepta × tri jezika (9 stranica)

| | DE | EN | NL |
|---|---|---|---|
| **A · Karta** (mapa naselja, SVG animacija) | `/` | `/en/` | `/nl/` |
| **B · Interaktiv** (WebGL teren + FTTH mreža) | `/concept-b/` | `/concept-b/en/` | `/concept-b/nl/` |
| **C · Punktwolke** (GeoExpert princip, plavo) | `/concept-c/` | `/concept-c/en/` | `/concept-c/nl/` |

Sve sekcije ispod hera (Bürgerservice, Leistungen, Projekte, Galerija, Kontakt…) su **identične** u sva tri koncepta. Razlikuje se samo hero.

## 3. Šta je urađeno u ovoj sesiji

1. **Konzept B — novi hero**: Three.js (r128, MIT, lokalno u `assets/vendor/`) digitalni model terena kao oblak tačaka sa sjenčenjem, izohipse, FTTH mreža (POP → trasa → razdjelnici → kućni priključci), svjetlosni impulsi duž trasa, čvorovi zasvijetle kad stigne signal. Miš: cijeli teren se blago pomjera (kao GeoExpert, bez lokalnog „ispupčenja"). Legenda DE/EN/NL. Fallback bez WebGL-a, `prefers-reduced-motion`, pauza van ekrana.
2. **Konzept C — nov**: hero 1:1 po GeoExpert principu (oblak tačaka, scan linija, panel s mjernim vrijednostima, isti raspored), ali u terraFIBER plavoj; optičke trase umjesto katastarskih parcela. Koordinate u panelu su ilustrativne (UTM, Münsterland) — natpis to označava.
3. **Header na svih 9 stranica**:
   - uklonjena bijela traka (Bürgerservice / telefon / radno vrijeme) — sadržaj i dalje postoji niže na stranici;
   - DE/NL/EN prebačeno u tamnu navigaciju pored menija;
   - traka „Ansicht wählen" sada tamnoplava, sa šrafurom, isprekidanom ivicom i žutom oznakom **ENTWURF / DRAFT / CONCEPT** (privremena, ukloniti prije objave);
   - stara „REDESIGN-STUDIE…" traka skrivena (CSS u `assets/v9.css`, markup ostao).
4. **Naslov hera (opcija A)**: DE *Vom ersten Plan bis zum Hausanschluss.* · EN *From first plan to home connection.* · NL *Van het eerste ontwerp tot de huisaansluiting.* — B i C naslov ~20 % manji.
5. **Konzept A na telefonu**: mapa iznad teksta. Popravljen horizontalni skrol na tablet širinama (768–1100 px).
6. **Favicon**: bijeli znak na plavom (`favicon.svg/.ico`, `apple-touch-icon.png`, `site.webmanifest`, `?v=2` cache-bust).
7. **Link preview (Viber/WhatsApp/LinkedIn)**: `assets/share-card.jpg` (+ `-en`, `-nl`), Open Graph tagovi, čisti naslovi stranica bez „Redesign-Studie".

## 5. Pravila koja važe

- Ne mijenjati granu `stable-v9-de-nl-en`.
- Ne mijenjati: fotografije i opise, projektne brojke, kontakte, kontakt formu (nema backend — ne smije lažno potvrditi slanje), Bürgerservice, prevode, `noindex`.
- Ne izmišljati firme podatke, reference ni kapacitete.
- Sve izmjene važe za sva tri jezika i (ako se tiču zajedničkih dijelova) za sva tri koncepta.
- Prije svakog pusha pokrenuti test (vidi dolje). GitHub Actions sam commituje screenshotove u `docs/screenshots/` → prije pusha uvijek `git pull --rebase`; kod konflikta na PNG-ovima uzeti novu verziju.

## 6. Kako se testira lokalno

```bash
cd terrafiber
python3 -m http.server 8123 --bind 127.0.0.1 &
NODE_PATH=/opt/npm-tools/node_modules node .github/qa/verify-concept-b.cjs
```
Za WebGL u headless Chromiumu test koristi SwiftShader (`--use-gl=angle --use-angle=swiftshader`).

## 7. Otvoreno / mogući sljedeći koraci

- Klijent bira A, B ili C → ostale ukloniti, ukloniti ENTWURF-traku.
- Popuniti stvarne podatke firme (kontakt forma backend, pravni tekstovi Impressum/Datenschutz).
- Prije objave: ukloniti `noindex` (meta + `_headers`), staviti pravi domen u `og:url`/`hreflang`.
- Eventualno: na desktopu kod Konzepta A takođe mapa iznad teksta (korisnik još nije tražio).
- Cijena za klijenta (Emir razmatra koliko naplatiti redizajn).
